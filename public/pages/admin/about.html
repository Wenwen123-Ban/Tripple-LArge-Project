About Click & Collect

What is Click & Collect?

Click & Collect is the Library Borrowing and Assistance System (LBAS) developed for the North Western Mindanao State College of Science and Technology (NMSC-ST). It is a web-based system that enables students to reserve and borrow library books online, and provides librarians with a complete set of tools to manage the library catalog, user accounts, circulation transactions, and operational rules.

Purpose

The system was created to modernize and streamline the library borrowing process at NMSC-ST — reducing manual paperwork, preventing duplicate reservations, and giving both students and librarians a clear, real-time view of book availability and circulation status.

Key Features

Online book reservation and borrowing for students — automated email confirmation and Gmail-verified account registration — real-time book lifecycle tracking (Available, Reserved, Borrowed, Due) — admin dashboard with overview statistics — bulk book import via CSV or Excel — Google Sheets catalog sync — librarian account management with multi-layer security — configurable borrowing and reservation rules — security logs and server health monitoring.

Technology Stack

Built with Python Flask as the backend framework, MySQL (XAMPP MariaDB) as the database, Bootstrap 5 and Vanilla JavaScript on the frontend, and Gmail SMTP for email notifications. Hosted locally with optional Cloudflare Tunnel for external access.
