📖 Librarian Manual

Getting Started as Admin

To access the admin portal:

1

Go to the login page and enter your Admin ID and Password.

2

The system checks your account type. If you are an admin, you are automatically redirected to the Admin Dashboard.

3

To log out, click the ☰ menu icon in the top-right of the navbar and select Log Out.

Dashboard

The dashboard shows a live overview of the library system:

  • Total of books — number of books in the catalog
  • Total of users — number of registered and verified students
  • Top 3 Most Reserved — books with the highest reservation count
  • Top 3 Most Borrowed — books with the highest borrow count
  • Reservation Area — pending student reservations awaiting admin approval
  • Borrowing Area — books currently borrowed by students

Control buttons in the table:

  • 🟩 Green button — Approve a reservation (moves book from Reserved → Borrowed)
  • 🟥 Red button — Reject/cancel a reservation (moves book back to Available)

Manage Books

  • Add Book — Fill in Title, select Category, enter Book No, then save
  • Add Category — Type a category name and click the green save button. Categories appear in both the book form and the Add Books dropdown. Delete a category using the ✕ beside it in the list
  • Search & Sort — Filter by status (Available, Reserved, Borrowed, Due), category, or sort by title or borrow frequency
  • Book row actions:
    • History — View full transaction history for that book
    • Force Return — Manually return a borrowed book with an audit note (admin only)
    • Notify — Send an email reminder to the borrower
  • Bulk Import — Upload a CSV or Excel file. Required columns: book_no, title. Optional: category. Use Dry Run to preview before committing
  • Google Sheets Sync — Paste the URL of a published Google Sheet to sync the catalog. Books with active reservations or borrows are never overwritten

Book Status Guide

  • Available — Book is in the library and can be reserved by students
  • Reserved — A student has reserved this book and it is awaiting your approval for pickup
  • Borrowed — Book is currently checked out to a student
  • Due — The return deadline has passed. The borrower should be notified and the book returned immediately

Manage Users

  • Sort By Admin — shows all admin accounts (ID, Name, LBC, Email, Address)
  • Sort By Student — shows all student accounts with additional sort options: by Course, Year, or Level (Junior High)
  • Add Admin — Click Add Admin +, fill in the form (no Course/Year for admins), click Confirm Gmail. An invitation email is sent to the new admin's Gmail. After they confirm, their one-time recovery code is shown privately on their screen only. You will see "Registration Complete" when done
  • Add Course — Type a course name and click the green save button. The new course immediately appears in the student registration form dropdown. Delete a course using the ✕ beside it
  • Delete Student Account — Click Delete beside the student row. Confirm in the dialog. The student receives an email notification with your contact details
  • Delete Admin Account — Click Delete beside the admin row. A confirmation email is sent to that admin. After they confirm, you receive a deletion code via the bell notification. Enter the code to finalize. You cannot delete your own account or the last remaining admin

Web Security

  • Logs Report — Live log of all system events: logins, failed attempts, account deletions, and more. Each entry shows the account ID, event type, IP address, and timestamp
  • Server Health — Click the Check button to see current CPU and RAM load. This can only be checked once per hour to avoid overloading the server. Status shows Normal, Moderate, or High Load
  • Reserve and Borrow Rules:
    • Nearest operation day — If a book is reserved on a holiday or non-operating day, the system automatically moves the pickup to the nearest valid day
    • Unapproved reservation expiry — Set how long a reservation stays pending before it auto- cancels (default 30 minutes)
    • Return deadline — Set the number of days and/or hours a student has to return a borrowed book. Leave blank for no deadline (N/A)

Forgot Password (Admin Recovery)

If you forget your admin password:

1

Go to the login page and click Forgot password click this

2

Enter your Admin ID, LBC No, and Gmail. All three must match your registered account exactly

3

Recovery is only available Monday to Friday, 8:00 AM to 5:00 PM. Attempts outside this window are blocked and logged

4

A 6-digit code is sent to your Gmail. Enter it on the recovery form

5

You will then be asked for your One-Time Setup Code — this is the physical code you wrote down when your account was first created. Without this code, recovery requires manual intervention from another admin

6

After both codes are verified, set your new password and log in normally

Notifications (Bell Icon)

  • A red badge on the bell icon means you have unread notifications
  • Notifications include: overdue book alerts, admin deletion confirmation codes, Google Sheets sync results
  • Unread notifications have a purple left border. Used notifications are greyed out and cannot be re-used
  • Click Clear All to remove read and used notifications. Active unread ones are never cleared automatically
