Managing Inventory

Our cataloging system uses a real-time sync with the central institutional database. Follow these steps for accurate record keeping:

  • 01 Scan ISBN or enter the Library of Congress classification number manually if the barcode is damaged.
  • 02 Verify the physical condition of the item and update the 'Condition' metadata field.
  • 03 Assign a specific storage bin or shelf location to ensure correct 'Collect' instructions for students.

badge Physical Institutional ID Card matching the system name.
qr_code_2 Digital Pickup QR code generated within the Student App.
contact_mail Institutional email verification if physical ID is unavailable.

Security Protocols

In the event of a security breach or system discrepancy, librarians are mandated to follow the 'Lavender Lockdown' protocol.

report

Critical Warning

Never share your librarian portal credentials. System logs are recorded per-user and are audited monthly for security compliance. Leaving your station logged in is a violation of institutional policy.

Protocol ALPHA: Data Breach

Immediate logout and notification of IT Support. All 'Click' events are paused until security clearance is provided.

Protocol BETA: Theft Recovery

Mark the item as 'Stolen' in inventory. The system will automatically flag the last verified borrower for review.
